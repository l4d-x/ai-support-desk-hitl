# Promo Codes and Gift Cards

## Using a promo code
Enter the code in the Promo Code box at checkout. Only one promo code can be used per order, and codes cannot be applied after the order has been placed.

## Gift cards
Gift cards never expire and can be used on any product. They are not refundable for cash and cannot be returned.

## Code not working
Codes may be expired, limited to certain products, or require a minimum spend. The checkout page shows the reason when a code is rejected.
